# Head First Design Patterns in Java ☕

This repository contains Java implementations of design patterns covered in the *Head First Design Patterns* book.

Each chapter is organized in its own directory under the `src/` folder, named with a prefix for ordering 
(e.g., `_01_strategy`, `_02_observer`, etc.).

## 📚 Purpose

The goal of this project is to:

- Reinforce understanding of classic design patterns
- Practice clean Java coding practices
- Follow along with the examples and exercises from the book

## 🗂️ Structure

Each pattern/chapter includes:
- Java code implementing the pattern
- Comments explaining the logic
- A `readme.md` inside the folder summarizing the pattern

## 📖 Implemented Patterns

- `_01_strategy` - Strategy Pattern
- `_02_observer` - Observer Pattern
